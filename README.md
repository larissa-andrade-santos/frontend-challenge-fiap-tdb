# Projeto - Turma do bem
 
Projeto desenvolvido pela equipe CODEXER para a disciplina de Front-End da FIAP, com o objetivo de aplicar os conhecimentos de HTML5 e CSS3 na construção de um site institucional para a organização Turma do Bem.

O site apresenta informações sobre a organização, seus projetos, a equipe de desenvolvimento e a solução proposta pelo grupo: o Farol, uma ferramenta de acompanhamento de doações.
 
## 🌐 Acesse
 
 https://github.com/larissa-andrade-santos/frontend-challenge-fiap-tdb.git
 
## Funcionalidades
 
- Página inicial: apresentação do projeto e informações principais.

- Sobre: informações sobre a organização Turma do Bem e seus projetos.

- Integrantes: apresentação dos desenvolvedores.

- FAQ: perguntas frequentes sobre o projeto.

- Contato: informações para contato.

- Farol: apresentação da solução proposta pela equipe.

- Funcionamento do Farol: explicação sobre o funcionamento da solução.

## Sprint 02 | Responsividade

Nesta etapa, o projeto recebeu melhorias de responsividade para proporcionar uma experiência adequada em diferentes tamanhos de tela.

Foram realizados ajustes em:

- Organização e adaptação dos elementos das páginas.

- Navegação e disposição dos links.

- Espaçamentos, fontes e tamanhos dos componentes.

- Distribuição de colunas e blocos de conteúdo.

- Imagens e demais elementos visuais.

## Breakpoints utilizados

Celular: até 480px.

Tablet: até 768px.

Desktop: acima de 768px.
