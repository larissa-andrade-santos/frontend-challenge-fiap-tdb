# Projeto - Turma do bem
 
Projeto foi desenvolvido como atividade da disciplina de Front-End da FIAP, com o objetivo de aplicar os conhecimentos de HTML e CSS na construção de uma página web.
 
## 🌐 Acesse
 
 
 
## Funcionalidades
 
- Página principal com informações sobre o projeto.
- Página de contato para que os usuários contatem a empresa.
- Página "Sobre" explicando os projetos da empresa.
- Página de integrantes, apresentando os alunos que desenvolveram o projeto.
- Página "FAQ" com as dúvidas frequentes dos usuários.
 
##  Tecnologias
 
- HTML5
- CSS3
